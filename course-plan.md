# Fundamentos de Desarrollo Web

## Resumen del Curso

Este curso de 1 hora introduce a estudiantes de secundaria a la creación de sitios web sencillos con HTML y CSS. Lección a lección, cada estudiante construye su propia página de perfil personal. **¡No requiere descargas!** Solo abre tu navegador web.

**Duración total**: ~60 minutos  
**Público objetivo**: Estudiantes de 12 a 17 años sin experiencia en programación  
**Prerrequisitos**: Ninguno  
**Herramientas necesarias**: **¡Solo tu navegador web!** (Chrome, Firefox, Safari o Edge)  
**Editor en línea**: [CodePen](https://codepen.io), gratuito

**📁 Repositorio de código fuente**: [https://github.com/upc-pre-202620-1asi0730-16127-databit/webdev-course-databit](https://github.com/upc-pre-202620-1asi0730-16127-databit/webdev-course-databit)

## Secuencia de Lecciones

### Lección 1: ¿Qué es el desarrollo web? (7 minutos)

- **Descripción**: Descubre qué es un sitio web, dónde vive y por qué HTML y CSS son su esqueleto y su ropa. Conoce CodePen, tu taller en línea, y haz tu primer cambio.
- **Enlace**: [Ver la lección](https://youtu.be/B91mMW147zY)
- **Conceptos clave**:
  - Un sitio web es un conjunto de páginas conectadas que viven en servidores.
  - Tu navegador le pide la página al servidor usando una URL.
  - HTML decide qué hay en la página y CSS decide cómo se ve.
- **Práctica**: [Clic para programar](https://codepen.io/) 👉 **¡No necesitas registrarte!**

---

### Lección 2: Introducción a HTML (8 minutos)

- **Descripción**: Aprende qué son las etiquetas, cómo es el esqueleto de toda página y crea tu primera página con títulos y párrafos.
- **Enlace**: [Ver la lección](PEGAR_YOUTUBE_L2)
- **Conceptos clave**:
  - Un elemento es la etiqueta de apertura, el contenido y la etiqueta de cierre.
  - Toda página tiene `<html>`, `<head>` y `<body>`.
  - Usa `<h1>` a `<h6>` para títulos y `<p>` para párrafos. Usa un solo `<h1>` por página.
- **Práctica**: [Clic para programar](PEGAR_PEN_L2) 👉 **¡No necesitas registrarte!**

---

### Lección 3: Añadir más elementos HTML (10 minutos)

- **Descripción**: Agrega listas, imágenes y enlaces para que tu página tenga más contenido.
- **Enlace**: [Ver la lección](PEGAR_YOUTUBE_L3)
- **Conceptos clave**:
  - `<ul>` crea listas con viñetas, `<ol>` crea listas numeradas y cada ítem va en `<li>`.
  - `<img>` no necesita cierre y lleva los atributos `src` y `alt`.
  - El atributo `alt` es muy importante para la accesibilidad.
  - `<a>` crea enlaces, y `href` indica a dónde llevan.
- **Práctica**: [Clic para programar](PEGAR_PEN_L3) 👉 **¡Comienza al instante!**

---

### Lección 4: Introducción a CSS (12 minutos)

- **Descripción**: Dale ropa a tu página con colores, fuentes, bordes y espacios.
- **Enlace**: [Ver la lección](PEGAR_YOUTUBE_L4)
- **Conceptos clave**:
  - Una regla de CSS tiene selector, propiedad y valor, como `h1 { color: purple; }`.
  - Las clases se llaman con un punto, como `.foto`.
  - Usa `color`, `background-color`, `font-family` y `font-size` para colores y letras.
  - Usa `border`, `border-radius`, `text-align`, `padding` y `margin` para bordes, centrado y espacio.
- **Práctica**: [Aplicar estilo con un clic](PEGAR_PEN_L4) 👉 **¡No es necesario registrarse!**

---

### Lección 5: Crear una página web sencilla (14 minutos)

- **Descripción**: Combina HTML y CSS paso a paso para construir tu página de perfil personal, depura errores y comparte tu resultado de forma segura.
- **Enlace**: [Ver la lección](PEGAR_YOUTUBE_L5)
- **Conceptos clave**:
  - `<div>` agrupa elementos en una caja.
  - Con `border-radius: 50%` una foto cuadrada se vuelve redonda.
  - `a:hover` cambia el estilo al pasar el cursor.
  - Por seguridad, no publiques tu dirección, teléfono ni datos privados.
- **Proyecto Final**: [Crea tu Perfil](PEGAR_PEN_L5) 👉 **¡Guarda y comparte!**

---

### Lección 6: Consejos y Próximos Pasos (9 minutos)

- **Descripción**: Conoce los errores más comunes, los hábitos de quienes programan y qué aprender después.
- **Enlace**: [Ver la lección](PEGAR_YOUTUBE_L6)
- **Conceptos clave**:
  - Revisa etiquetas sin cerrar, puntos y coma, nombres de clases y enlaces de imágenes.
  - Usa sangría, comentarios y nombres claros, y prueba después de cada cambio.
  - Valida tu código con el [validador de W3C](https://validator.w3.org).
  - Sigue aprendiendo con [MDN Web Docs](https://developer.mozilla.org/es/).
- **Práctica**: [Encuentra los errores](PEGAR_PEN_L6) 👉 **¡Comienza al instante!**
