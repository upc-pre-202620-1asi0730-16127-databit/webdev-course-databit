# Guión — Lección 5: Proyecto final: Mi perfil personal

Duración estimada: 8-10 minutos

## PORTADA

LOCUTOR: ¡Hola\! Hemos llegado a nuestra última lección. En las clases anteriores aprendiste a utilizar HTML para crear contenido y CSS para darle estilo a tus páginas web.

Hoy vamos a poner todo en práctica con un proyecto final: ¡crear tu propio perfil personal\! Podrás presentarte, compartir tus gustos y personalizar tu página. ¡Comencemos\!

## ¿QUÉ VAMOS A CREAR?

LOCUTOR: Nuestro proyecto será una página de perfil personal que incluirá una fotografía, tu nombre, una pequeña presentación, tus hobbies, tu música favorita y algunos enlaces de interés.

Para construirla utilizaremos dos archivos: `index.html` para el contenido y `style.css` para los estilos.

## CONSTRUIMOS NUESTRO PERFIL CON HTML

LOCUTOR: Primero, abre tu archivo `index.html`.

Vamos a crear un contenedor principal utilizando la etiqueta `<div>` y la clase `perfil`. Dentro colocaremos toda nuestra información.

Comenzaremos agregando una imagen con `<img>`, utilizando los atributos `src` y `alt`. Después colocaremos un título `<h1>` con nuestro nombre y un párrafo con la clase `frase` para describirnos.

A continuación, agregaremos diferentes secciones utilizando títulos `<h2>`:

- Sobre mí: un pequeño párrafo para presentarnos.
- Mis hobbies: una lista desordenada `<ul>` con nuestras actividades favoritas.
- Mi música favorita: una lista ordenada `<ol>` con tres canciones.
- Mis enlaces: un enlace `<a>` a una página web de nuestro interés.

¡Listo\! Ya tenemos organizada la información de nuestro perfil.

## PERSONALIZAMOS CON CSS

LOCUTOR: Ahora abre tu archivo `style.css`. ¡Es momento de darle personalidad a nuestra página\!

Primero trabajaremos con `body`, donde cambiaremos el fondo, el tipo de letra y los márgenes.

Después seleccionaremos `.perfil` para definir su ancho, color de fondo, espacio interno y bordes redondeados.

También personalizaremos la imagen `.foto`, los títulos, los párrafos, las listas y los enlaces.

Recuerda que puedes utilizar propiedades como `background-color`, `color`, `font-size`, `border-radius` y `text-align`.

¡Experimenta con diferentes colores y estilos hasta conseguir el diseño que más te guste\!

## ¡TU TURNO\! CREA TU PERFIL PERSONAL

LOCUTOR: ¡Llegó tu momento\!

Pausa el video y completa tu proyecto siguiendo estas indicaciones:

1. Agrega tu fotografía, nombre y presentación.
2. Completa la sección «Sobre mí».
3. Crea una lista con cuatro hobbies.
4. Agrega tus tres canciones favoritas.
5. Coloca un enlace a una página web de tu interés.
6. Personaliza tu perfil utilizando CSS.

Recuerda guardar tus cambios y comprobar cómo se visualiza tu página en el navegador.

## RETOS OPCIONALES PARA QUIEN TERMINE ANTES

LOCUTOR: ¿Terminaste? ¡Te propongo algunos desafíos adicionales\!

- Cambia los colores por los de tu videojuego o equipo favorito.
- Agrega una sección llamada «Mis metas».
- Cambia el borde por `dashed` o `dotted`.
- Agrega un segundo enlace.
- Incorpora un efecto `:hover` a tu imagen.

¡Anímate a personalizar todavía más tu página\!

## REPASO RÁPIDO

LOCUTOR: Antes de terminar, repasemos:

Segunda pregunta: ¿qué utilizamos para cambiar colores, tamaños y bordes? ¡CSS\!

Y última pregunta: ¿para qué sirven las clases? Para identificar elementos y aplicarles estilos.
